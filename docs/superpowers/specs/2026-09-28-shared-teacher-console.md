# 共用教師控制台（使用者已批准）

## 存取

正式教師頁只要求口令 `admin`，不要求帳號；移除改密碼及永久刪除功能（包含伺服器路由）。這是刻意提供共用存取，不宣稱私人教師身份驗證。保留姓名／班別／装置、分數、Excel 匯出，頁面清楚標示共用入口。保留同源檢查、CSRF、HttpOnly Cookie、限流、session 時限及稽核。

保留歷史管理員資料，不重設舊帳號。共用入口使用獨立的內部服務身份；舊登入介面不再對正式環境開放。現有非破壞性房間管理保留雙重確認。

## 版面

四區：總覽（統計及房間）、對戰紀錄、學生排行榜、歷史高分設計。每次只顯示一區，日期及篩選共用；分頁保留，維持原字體與配色。

## 靜態 3D

對戰紀錄及高分設計直接顯示三層、孔位及下方金屬片的固定視角立體縮圖。使用已儲存的形狀、尺寸、角度、圓角及自定輪廓，不能改用目前學生設計。排行榜以篩選範圍內最高分場次為代表，同分以時間及穩定 ID 排序；標明場次日期及分數，可切至該學生歷史紀錄。資料不足時明示，不能捏造幾何。

以 Three.js 幾何投影成靜態 SVG（三角面深度排序）避免每筆長駐 WebGL context；縮圖無旋轉／連續動畫，適用手機及 iPad。沿用已驗證造型建模；不影響學生端。

## 驗收

新增口令正誤／舊 payload 拒絕／CSRF／過期／限流測試，停用刪除與改密碼路由測試；歷史最高分 SQL／protocol 測試、基本及自定縮圖測試、四頁籤及手機桌面瀏覽器驗收。完整測試與 PostgreSQL CI 通過後才部署，再以公開口令核實教師紀錄、排行榜、高分設計及 Excel。不得刪除學生資料。
