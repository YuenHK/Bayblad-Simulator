# 60 秒生肖對戰實作與驗收

已由使用者批准全部需求及每輪 60 秒時間安排，直接完成實作與部署。

架構：伺服器維持唯一賽果與時間軸。未發射者於截止時採 Miss 最低倍率；雙方結果齊備才排程。每輪 0–48 秒競技場，48–54 秒召喚，54–60 秒最後一擊，第 60 秒公布結果。三局兩勝。

- [x] 伺服器與 protocol：加入同步演出資料、60 秒影格排程；測試零輸入、單方输入、雙方與斷線重連。
- [x] BattleArena3D：沿用 Three.js 及真實設計形狀，原創十二生肖立體模型、攝影機、粒子、近鏡及技能名稱；提供 WebGL 失效提示／備援。
- [x] RoomPage：同步場景、結束返回同房重賽，學生不得看對方判定。
- [x] 電腦玩家：僅房主於等待中加入空位、伺服器隨機判定；以真人歷史使用次數最高的結構設計為依據，排除機器對戰自增人氣。
- [ ] 驗收：型別、單元、整合測試；瀏覽器完整 60 秒時間與結束演出、真人對機器及雙真人重賽，發布前核對部署版本。

技能名称來源：教育部辭典「龍騰虎躍」「虎嘯風生」等古典詞語作原創生肖招式命名參考，使用整理好的固定庫隨機選擇，不在對戰期間查詢網路。

技術界線：60 秒為共同演出時間；伺服器先以原有物理模型計算權威軌跡及賽果，再將軌跡重採樣至 60 秒，尾聲鏡頭／神獸屬視覺演出，不另加計分優勢。不是宣称真實陀螺必定旋轉 60 秒。模型為原創低多邊形生肖，不使用動畫作品角色或素材。

本地證據：`pnpm test` 通過 1,098 個測試，32 個環境相關測試略過；`pnpm test:cinematic` 實際播放兩輪完整 60 秒並返回同房再準備通過。公開部署與資料庫驗收待最後完成。
