# 電腦玩家採用全部歷史學生排行榜榜首代表設計

使用者確認使用全部歷史，不受教師頁目前日期／班別篩選影響。

1. 以教師排行榜同一種歷史 canonical identity snapshot，累計已完成真人對戰的對戰分＋挑戰分。
2. 總分最高者為榜首；同分沿用教師表格的學生名稱、身份 ID 排序。
3. 在榜首的紀錄中採用最高分場次設計；同分較新完成、賽事 ID、玩家席位排序。
4. 只使用合規設計。榜首無可用合規設計／沒有紀錄時使用預設設計，不冒充其他名次。
5. 每次電腦玩家重新準備時查詢當前榜首；保留隨機發射、學生歷史及全部外觀。
6. 先以回歸測試證明累計冠軍可以勝過全站單場冠軍，再實作；核對教師查詢、身份快照、兩席位及自定輪廓，通過 CI 後公開部署。
7. 不新增第 51 場實機對戰；公開僅使用觀賽房主載入電腦，不觸發比賽。
