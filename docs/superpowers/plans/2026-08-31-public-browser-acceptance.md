# 公開網站跨瀏覽器驗收及統一修復計劃

> **面向 AI 代理的工作者：** 必需子技能：使用 systematic-debugging、test-driven-development 及 verification-before-completion；步驟使用復選框追蹤。

**目標：** 以正常、獨立訪客、電腦、手機及 iPad 情境驗證公開學生端與老師端，集中記錄問題後按根因統一修復及部署。

**架構：** 首輪公開環境測試只收集瀏覽器、網絡、畫面及伺服器證據。每個可重現問題先加入最小失敗測試，再修改對應前端、即時服務或後台；最後用同一矩陣作公開回歸。

**技術棧：** Chrome、Chromium、Firefox、WebKit、Playwright、React、Socket.IO、Fastify、Render、GitHub Pages。

---

### 任務 1：環境及基線

- [ ] 確認學生端、老師端及 `/health/ready` 公開網址可達。
- [ ] 記錄目前 Git commit、Render 版本、瀏覽器及測試 viewport。
- [ ] 執行現有學生、對戰、老師及響應式 E2E，保存失敗證據。

### 任務 2：學生端首輪真實操作

- [ ] 正常工作階段：修改三層參數、排序、金屬碟、驗證限制、三種預覽及保留設計。
- [ ] 獨立訪客工作階段：建立／加入房間、讓位、觀賽、準備、三輪發射、賽後計分、離線恢復及關房。
- [ ] 390×844、768×1024、820×1180、1024×768、1440×900 驗證三頁籤、橫直向、44px 操作目標及無頁面級橫向溢出。
- [ ] Chromium、Firefox、WebKit 執行相同核心流程；WebKit 作為 Safari／iPad 相容性證據。

### 任務 3：老師端首輪真實操作

- [ ] 以 `admin` 登入公開 `/admin/`，驗證錯誤密碼、工作階段、登出及重新登入。
- [ ] 驗證房間、紀錄、日期／班別篩選、排行榜、每天／每週／每月統計、參數高低分分析及 Excel 匯出。
- [ ] 危險操作只驗證雙重確認及取消；不永久刪除真實資料。
- [ ] 在桌面、手機及 iPad 尺寸檢查溢出、對話框、鍵盤焦點與觸控操作。

### 任務 4：根因、TDD 與統一修復

- [ ] 每個問題記錄固定重現步驟、實際／預期結果、瀏覽器、viewport、網絡及伺服器證據。
- [ ] 先加入最小失敗測試並確認紅燈；一次只修一個根因。
- [ ] 執行目標測試確認綠燈，再跑相鄰測試；不更改既有字體、字級、字型或配色。

### 任務 5：完整回歸與部署

- [ ] 執行 `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm test:e2e`。
- [ ] 對 Chromium、Firefox、WebKit 執行學生及老師核心 E2E。
- [ ] 推送 `main`、部署 Render／GitHub Pages，確認公開 commit 及健康檢查。
- [ ] 用相同公開矩陣重跑，交付通過、修復、未解及實體 iPad 限制報告。
