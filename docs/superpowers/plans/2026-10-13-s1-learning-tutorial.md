# 中一實驗室及操作教學實作計劃

> 歷史計劃：使用者其後確認移除實驗室與操作教學。現行修訂見 `2026-10-13-layer-preview-refresh.md`；以下為舊版本的設計及驗收紀錄，不代表目前提供該功能。

使用者已批准：實驗模式、設計版本比較、簡短實驗紀錄，以及可跳過、可重開的實作教學。沿用正式設計室字體、配色及對戰引擎，不改教師登入。

## 邊界

實驗室只用本機瀏覽器的獨立儲存鍵。正式草稿不會被練習覆蓋；只有明確按「帶回設計室」才取代正式草稿。紀錄可匯出 CSV，並清楚說明無痕視窗及清除網站資料會失去紀錄。本輪不新增教師資料庫表。

物理運算放在 Worker，固定對手、種子與力度；列出模型結果而不提供最優參數或策略。教學房間是本機練習，不會建立公開房、上載設計、增加分數或影響冠軍電腦選型。正式 Chrome 驗收已達 50 場，不再增加正式場次。
