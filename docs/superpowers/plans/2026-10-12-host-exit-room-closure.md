# 房主離房與空房自動關閉

使用者已批准邊測試邊加入功能，並確認關閉分頁也關房，短暫斷線／重新整理保留緩衝。

## 行為

- 房主明確離房或切換到設計室／大廳：立即關房，通知所有參與者；進行中的對戰取消，不新增完成分數，歷史紀錄保留。
- 非房主離房：只退出本人；沒有已連線真人時關房，電腦玩家不算真人。
- 關閉分頁：pagehide 以既有 session token 發送離頁通知；伺服器給 10 秒重連緩衝，重連取消通知。通知不保證送達，後備是原有 120 秒斷線逾時清理。
- 純斷線不發送離頁通知，保留 120 秒；房主最終逾時後關房，不再轉移房主。
- 任何關房都沿用權威鎖、持久化投影及 socket 清理，禁止刪除學生／歷史資料。

## 執行及驗收

1. 先新增 room service、socket、HTTP、前端測試，覆蓋房主／非房主權限、空房、重連取消、通知驗證及比賽中離房。
2. 房間服務採用關閉判定；即時服務統一持久化關房；離頁端點限定合法 Origin、有效 token、限長 body，無 token 或外站不能關房。
3. 前端導航等待離房確認，pagehide／pageshow 管理重連；保持全部外觀設計不變。
4. 完整測試及安全 CI 全過後部署，公開驗收同房主動退出、非房主離房、空房及重新整理。
5. 100 場實際 Chrome 人機測試已開始，沿用原設計並保存 CSV，不將 API／自動化測試計入。
