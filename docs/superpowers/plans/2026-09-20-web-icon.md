# 網頁 ICON 實作計劃

**目標：** 為陀螺設計器加入可辨識的分頁及主畫面圖示，不修改頁面文字、字體或樣式。
**設計：** 採用原有深藍背景、青藍／紫色陀螺與能量環；不放文字，兼顧小尺寸辨識。使用者已授權清晰範圍的工作直接完成。
**架構：** 同一 SVG 母版衍生 PNG（32/180/192/512）及 ICO；HTML 使用 Vite BASE_URL 連結，manifest 保持 browser 顯示模式，不加入 service worker。
