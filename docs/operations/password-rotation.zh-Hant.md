# 管理員密碼與歷史清理

## 更換既有帳號密碼

1. 開啟教師後台並登入。
2. 按「更改密碼」，自行輸入目前密碼及至少 12 個字元的新密碼，重複輸入確認。
3. 按「儲存新密碼並登出」。所有裝置的舊教師登入階段及重新驗證授權會失效。
4. 使用新密碼重新登入，並確認舊密碼不能登入。

新密碼只傳送到同源 HTTPS 後端，以 Argon2id 雜湊儲存，不放在網址、瀏覽器本機儲存、稽核內容或 Git 中。密碼更新、登入階段撤銷及稽核紀錄在同一資料庫交易完成；登入建立階段亦檢查密碼版本，避免換密碼期間的舊登入要求繼續生效。

`ADMIN_INITIAL_PASSWORD` **只在帳號首次建立時使用**，變更此環境設定不會重設既有帳號。正式密碼與初始化密碼均不可放進文件、測試、截圖或程式庫。

## 2026-09 歷史清理後的開發注意事項

已替換 `main` 及 `codex/game-ui` 舊提交中的曝光密碼，提交編號因此改變。請重新複製儲存庫；不要把舊副本合併或直接推送到新的歷史，以免重新公開敏感內容。有未提交的工作時，先保留並檢查純程式變更，再移植到新副本。

刪除檔案或重寫歷史不代表舊密碼安全，仍須更換實際密碼。別人的複本、分叉、舊 Pull Request 參照及 GitHub 快取不受一般分支推送控制；必要時按 [GitHub 官方敏感資料清理指引](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository) 聯絡 GitHub Support。
